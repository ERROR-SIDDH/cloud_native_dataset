# Dataset — Analysis and Visualization of Cloud-Native Attacks in a Secure Testbed

This repository contains the dataset published with the research paper:

**“Analysis and Visualization of Cloud-Native Attacks in a Secure Testbed”**

[![DOI](https://img.shields.io/badge/DOI-10.5121%2Fijcnc.2026.18206-blue)](https://doi.org/10.5121/ijcnc.2026.18206)

## Dataset Contents

The dataset is provided in four formats/versions:

1. **CSV converted from PCAP files**
   Network traffic extracted from the raw PCAP captures and converted into CSV format for analysis and machine learning.

2. **Initial Augmented CSV Files**
   CSV datasets generated after the initial data augmentation process.

3. **Raw Network Captures (`.pcap`)**
   Original network traffic captures collected from the secure testbed in PCAP format.

4. **SMOTE-Augmented CSV Files**
   CSV datasets generated using the **Synthetic Minority Over-sampling Technique (SMOTE)** to address class imbalance.

## Paper

For details about the testbed, attack scenarios, data collection methodology, and analysis, refer to the published paper:

**Analysis and Visualization of Cloud-Native Attacks in a Secure Testbed**
DOI: https://doi.org/10.5121/ijcnc.2026.18206
